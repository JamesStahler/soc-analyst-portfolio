# Google Cybersecurity Professional Certificate Labs

This directory contains selected hands-on coursework completed through the eight-course Google Cybersecurity Professional Certificate. The work supplements my systems and networking projects with foundational experience in security operations, risk analysis, incident documentation, and security tooling.

## Project Areas

- **[GRC](./grc)** — risk assessments, control reviews, compliance concepts, threat modeling, and asset classification
- **Incident response** — incident reports, phishing analysis, investigation documentation, and threat-intelligence concepts
- **Network security** — network traffic analysis, tcpdump, and Wireshark concepts
- **Linux, SQL, and Python** — Linux permissions, SQL filtering, and introductory Python security tasks
- **Credential** — completion credential

## Skills Represented

- NIST Cybersecurity Framework fundamentals
- Security controls and risk assessment
- Incident-response documentation
- SIEM and IDS concepts
- Network-security analysis
- Linux, SQL, and Python foundations
- Clear communication of technical findings and recommendations

## Coursework Note

Some scenarios, data, and document templates were supplied by the course. The completed analysis, responses, and recommendations represent my coursework and are presented as educational projects rather than professional client engagements.
