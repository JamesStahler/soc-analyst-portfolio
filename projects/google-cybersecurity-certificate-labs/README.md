# Google Cybersecurity Professional Certificate Labs

Selected hands-on coursework completed through the eight-course Google Cybersecurity Professional Certificate.

Folders are organized by cybersecurity domain:

- `grc/` — risk assessments, controls, compliance, threat modeling, and asset inventory
- `incident-response/` — incident reports, phishing analysis, investigation documentation, and threat intelligence concepts
- `network-security/` — network traffic analysis, tcpdump, and Wireshark concepts
- `linux-sql-python/` — SQL filtering and Python security foundations
- `credential/` — verified completion certificate

Some documents use course-provided templates. The completed analysis and responses represent my coursework.
